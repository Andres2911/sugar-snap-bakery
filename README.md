# Sugar-Snap Bakery

Puzle de alquimia pastelera (español e inglés): mueve, mezcla y transforma materia mágica para despertar los dulces dormidos de Auralia. 120 niveles en once regiones, un Obrador sin fin y un reto cada día.

**Jugar:** https://andres2911.github.io/sugar-snap-bakery/

Esta carpeta es la versión preparada para YouTube Playables: carga el SDK oficial antes que el juego, guarda el progreso con `ytgame.game.saveData`/`loadData`, respeta el silencio y la pausa de YouTube, y usa sólo archivos locales con rutas relativas. Fuera de YouTube funciona como una página web normal y guarda en el navegador.

Se genera con `node herramientas/version_playables.js` desde el proyecto principal.
